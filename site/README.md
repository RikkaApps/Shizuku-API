# مهام الكويت (نموذج تجريبي)

موقع ثابت بلا بناء: افتح `site/index.html` أو انشره على GitHub Pages / أي استضافة ثابتة (يلزم HTTPS لتثبيت التطبيق والإشعارات).

الميزات: عروض أسعار، أمانة (escrow)، تقييمات، توثيق هوية، إبلاغ، تصفية بالمنطقة وخريطة، إشعارات، PWA، صفحات الشروط والخصوصية والاسترجاع.

**محاكاة في هذه النسخة:** التخزين في localStorage، الدفع، التوثيق، وإشعارات واتساب/الجوال في الخلفية.
للإطلاق الفعلي يلزم: خادم وقاعدة بيانات، بوابة دفع مرخّصة (مثل KNET/MyFatoorah)، مراجعة هوية فعلية، Web Push وWhatsApp Business API، ومراجعة قانونية للنصوص.
